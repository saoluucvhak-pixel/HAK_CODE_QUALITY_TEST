# HAK Code Quality Test

Khung kiểm tra chất lượng mã nguồn cho các ứng dụng HAK.

## Thành phần mục tiêu
- Code Quality: lint, kiểm thử, phát hiện mã trùng và lỗi phổ biến.
- Architecture Analyzer: sơ đồ phụ thuộc, ranh giới module và kiến trúc.
- Observer: nhật ký kiểm thử, đo lường hiệu năng và phát hiện lỗi.
- Dashboard: tổng hợp kết quả kiểm tra, xu hướng và cảnh báo.

## Trạng thái
Repository khởi tạo. Các thành phần trên là phạm vi kế thừa được xác định, chưa có mã nguồn được nhập vào repository này.
